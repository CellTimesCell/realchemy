# ⚗️ REALCHEMY (Реалхимия)

> **Алхимия с реальными предметами и настоящей химией.**
> Игрок попадает в ситуацию выживания, получает набор реальных предметов и, комбинируя их по законам земной физики и химии, собирает то, что нужно для выхода из кейса. Часть процессов идёт в реальном времени — даже когда игра закрыта.

| Параметр | Значение |
|---|---|
| Жанр | Puzzle / Crafting / Survival, оффлайн, одиночная |
| Платформы | Android → Steam (Windows/Linux). iOS — позже |
| Движок | **Godot 4.7.x stable** (GDScript) |
| Визуал | 16-битный пиксель-арт в духе Sega Genesis (см. `docs/ART_PIPELINE.md`) |
| Арт | Генерация ИИ + ручная чистка в Aseprite |
| Монетизация | Бесплатный пробный период → разовая покупка ~$5.99–6.99, **без рекламы**, DLC с новыми кейсами |
| Статус | Pre-production, документы v1.0 (17.10.2026) |

## История решений (кратко)

| Когда | Решение |
|---|---|
| Фев 2025 | Идея «Алхимии»: предыстория → инвентарь → комбинации → цель. Прототип на Python |
| Мар 2025 | Принцип: окружение и предметы ультрареалистичны, цель — неожиданная |
| Апр 2026 | Godot 4 + GDScript, JSON для данных, ConfigFile для сохранений, EventBus, State Machine, Unix-таймеры. Бэкенд отложен |
| Май 2026 | Временный переход на Unity 6 (GDD v2, 10 кейсов) |
| Июль 2026 | **Возврат на Godot** — текстовые `.tscn`/`.gd`, лучше для работы с Claude, без лицензий |
| Окт 2026 | Полностью оффлайн, облачные сохранения через платформу, DLC вместо онлайна. Пробный период + разовая покупка, без рекламы |
| **17.10.2026** | **Химия опирается на реальную науку.** Таймеры = реальная длительность процессов (масштабированная). Арт — 16 бит |

## Фазы

| Фаза | Цель | Критерий готовности |
|---|---|---|
| **−1. Окружение** | Софт, репозиторий, MCP, индексация | Пустой проект запускается из Claude Code, Android-сборка ставится на эмулятор |
| **0. Прототип** | 1 кейс на плейсхолдер-арте | Можно пройти кейс от начала до победы/поражения, таймер переживает закрытие |
| **1. Вертикальный срез** | 3 кейса, финальный стиль, звук | Не стыдно показать друзьям и записать видео |
| **2. MVP Android** | 10 кейсов, энциклопедия, покупка | Закрытый тест в Google Play |
| **3. Steam** | Страница, вишлисты, GodotSteam | Публичная страница Steam |
| **4. Релиз** | 20–30 кейсов | Релиз Android + Steam |

Детали задач — в `TASKS.md`.
