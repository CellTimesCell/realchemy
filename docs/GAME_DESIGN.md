# Realchemy — Game Design (v1.0)

## 1. Питч
**Одной фразой:** «Выживи, зная химию: реальные предметы, реальные реакции, реальное время».

**Чем отличается от Little Alchemy:** там «огонь + вода = пар» по логике слов. Здесь — по законам природы: известняк в огне становится негашёной известью, она с водой греется и даёт гашёную, а из неё и песка получается раствор. Игрок, прошедший игру, реально знает немного больше о мире.

## 2. Core loop
```
Кейс (предыстория + цель + стартовые предметы)
  → осмотр предметов (свойства, состав)
  → комбинирование: предмет + предмет / предмет + зона (огонь, вода, солнце)
  → результат: новое вещество | ничего | побочный эффект
  → долгие процессы уходят в реальный таймер (сушка, брожение, ржавление)
  → цель собрана → победа → факты в Энциклопедию
```
Каждые 30 секунд игрок: берёт предмет → пробует действие → видит реакцию (звук, частицы, текст).

## 3. Модель «настоящей химии»
Предмет — это не просто иконка, а набор свойств:

| Свойство | Пример | Зачем |
|---|---|---|
| `composition` | известняк → CaCO₃ | энциклопедия, логика реакций |
| `phase` | solid / liquid / gas / powder | что во что можно налить/насыпать |
| `tags` | `flammable`, `acidic`, `alkaline`, `metal`, `organic`, `fuel`, `container` | реакции по тегам, а не только по ID |
| `temperature` | cold / ambient / hot / burning | нагрев как условие |

**Типы действий (глаголы):**
`combine` (смешать), `heat` (огонь), `cool`, `dissolve` (в воду), `grind` (растереть камнем), `filter` (ткань/песок), `evaporate` (солнце/огонь), `wait` (реальное время), `connect` (электричество).

**Реакции срабатывают двумя способами:**
1. Точный рецепт: `wood + fire(heat, без воздуха) → charcoal`.
2. По тегам (запасной путь, чтобы мир казался живым): `любой flammable + fire → ash + heat`. Это даёт «неожиданные» результаты без ручного описания каждой пары.

**Неудачи учат:** ошибочная комбинация не просто «ничего», а объяснение: «Медь не реагирует с водой — нужна кислота или соль».

## 4. Реальное время
Длительность берётся из реального процесса и масштабируется:

| Процесс | В реальности | В игре (пример) |
|---|---|---|
| Выпаривание соли из морской воды на солнце | дни | 30–60 мин |
| Брожение фруктов в уксус | недели | 2–6 ч |
| Рост плесени на хлебе | несколько дней | 3–8 ч |
| Ржавление железа в солёной воде | дни | 1–2 ч |
| Обжиг глины | часы | 5–15 мин |
| Сушка древесины / мяса | дни | 1–3 ч |

Правила: короткие процессы (< 1 мин) идут сразу с анимацией; длинные — в слот «Процессы» с таймером на Unix timestamp. Пока процесс идёт, игрок делает другое (это решение от 06.10.2026). Уведомление Android о завершении — фаза 2.

*Открытый вопрос:* может ли кейс провалиться, пока игра закрыта (общий таймер кейса), или реальное время только «доращивает» процессы.

## 5. Пример дерева реакций (кейс «Берег после кораблекрушения»)
Цель: развести сигнальный огонь и сделать сосуд для пресной воды.
```
кремень + стальной нож (удар) → искры
сухая трава + искры → огонь (зона)
древесина + огонь (в яме, без воздуха) → древесный уголь
глина + вода → пластичная глина → [лепка] → сырой горшок
сырой горшок + огонь (wait 10 мин) → керамический горшок
морская вода + горшок + огонь → пар + соль
пар + холодный камень → пресная вода (конденсация)   ← цель 2
уголь + зелёные листья + огонь → густой дым            ← цель 1
```
Каждый шаг — реальная физика/химия с фактом в энциклопедии.

## 6. Пул безопасных реальных реакций для контента
Обжиг известняка в известь; гашение извести; известковый раствор; глина → керамика; песок + сода + огонь → стекло (упрощённо); древесина → уголь (пиролиз); зола + вода → щёлок; жир + щёлок → мыло; брожение сахара → спирт → уксус; плесень на хлебе; выпаривание соли; дистилляция/конденсация воды; ржавление железа; лимон + медь + цинк → батарейка; магнит + проволока + движение → ток; окисление меди (патина); сода + уксус → углекислый газ (тушение огня); крахмал + йод (индикатор); краснокочанная капуста как индикатор pH; дубление кожи танинами коры; смола + уголь → клей; фильтрация воды через песок и уголь.

Запрещённые направления — см. `CLAUDE.md` §6.

## 7. Кейсы — структура
- **Предыстория** (2–4 предложения, можно с юмором).
- **Окружение** (реальное или фантастическое, но физика всегда земная).
- **Стартовые предметы** (6–12), часть — лишние/отвлекающие.
- **Зоны** (огонь, море, солнце, камень-наковальня…).
- **Цель(и)** — иногда «абсурдная, но выполнимая» (идея марта 2025).
- **Ограничение** — таймер кейса ИЛИ лимит действий ИЛИ без ограничений (обучающие).
- **Генерация вариаций:** один кейс может выдавать разные наборы предметов из пула (идея февраля 2025) — фаза 2+.

Черновой список кейсов: берег после кораблекрушения, полярная станция без тепла, заброшенная шахта, средневековая кухня, школьная лаборатория после отключения света, пещера Дракулы (фэнтези-окружение, реальная химия), «сделай человека счастливым» (биохимия гормонов на уровне научпопа — фаза 3).
10 подробных кейсов из GDD v2 — в `docs/archive/`, перенести с адаптацией под реальную химию.

## 8. Энциклопедия (Codex)
Каждая открытая реакция/вещество — карточка: пиксельная иконка, формула, факт, «где встречается в жизни». Это и мотивация собирать всё, и маркетинговый крючок («игра, после которой понимаешь, как сделать мыло на необитаемом острове»).

## 9. Подсказки
3 уровня: намёк по тегам («Тебе нужно что-то щелочное») → какой предмет участвует → полный шаг. Бесплатные с перезарядкой по реальному времени. Без продажи подсказок за деньги (решение «без pay-to-win»).

## 10. Монетизация
Пробный период (несколько кейсов / дней) → разовая покупка. Без рекламы. Платные DLC-паки кейсов. Косметика (темы верстака) — опционально.
