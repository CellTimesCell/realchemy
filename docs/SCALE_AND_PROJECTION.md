# Масштаб и проекция — обязательная проверка (v1.0, 22.10.2026)

Источник: замечания Александра по спальне v2 (R3). Читать перед КАЖДОЙ расстановкой предметов и перед каждым показом. Дополняет чек-лист ART_PIPELINE §3.6.

## 1. Эталон масштаба
- Герой ≈ 60–63 px. Всё меряется от него.
- Дверь ≈ 1.4–1.6 роста героя, стоит на полу.
- Кровать с балдахином: ширина ≈ 2.5–3 роста героя, матрас ≈ по бедро герою.
- Тумба: столешница чуть ниже края матраса.
- Стул/кресло: сиденье ≈ по колено, спинка ≈ по грудь.
- Сундук: ≈ по колено.
- Книжный шкаф, часы напольные: 1.5–2 роста героя.
- Камин (очаг): проём ≈ по пояс–грудь герою; огонь ЗАПОЛНЯЕТ нижнюю треть–половину проёма, стоит на дровах на дне очага.
- Свеча ≈ 6–10 px; подсвечник/канделябр — по размеру поверхности, на которой стоит.
- Текст на баннерах/табличках — читается с первого взгляда при 640×360 (иначе крупнее носитель, а не мельче шрифт).

## 2. Проекция (камера-диорама, чуть сверху)
- Задняя стена — фронтально. Предметы у неё — фронтальный вид.
- Боковые стены — в перспективе. Предметы на них/у них — в ракурсе 3/4 к центру комнаты; навесные — трапецией по линиям стены.
- Пол — в перспективе: ковры, шкуры, разбросанные предметы лежат ПО ПЛОСКОСТИ ПОЛА (сжаты по вертикали), а не стоят «картинкой к зрителю».
- Предмет внутри другого (огонь в камине, книга на полке, свеча на тумбе) — в координатах и масштабе того предмета: нижняя точка опирается на его поверхность.

## 3. Опора и контакт — ничего не «летает»
- У каждого предмета есть точка опоры: пол, стена (крепление/гвоздь/кронштейн), поверхность другого предмета.
- Контактная тень на полу/стене обязательна.
- Огонь — на дровах на дне очага, не в углу проёма. Свечи — в подсвечниках на поверхности.

## 4. Логика размещения
- Мебель у стен — вплотную к стене (тумбы, шкафы, сундуки), если по смыслу не стоит посреди комнаты.
- Предметы группируются по смыслу в «уголки»: у камина — кресло/качалка + шкура + стопка книг (тут читают у огня).
- Не оставлять пустых углов, если комната жилая: в каждом углу — предмет или осознанная пустота (проход).
- Не ставить декор «просто между» двумя элементами (например, канделябр точно между горгульями) — каждый предмет на своём месте по смыслу.
- Однотипные предметы на полу: не один «валяющийся», а композиция (одна книга + стопка рядом).

## 5. Проверка перед показом (каждый предмет)
1. Размер относительно героя и соседних предметов (по §1).
2. Ракурс по стене/полу (§2).
3. Опора и тень (§3).
4. Смысл места (§4).
5. Читаемость (текст, силуэт) при 640×360.
Если хоть один пункт не выполнен — переделать до показа, а не перечислять в «не исправил».
